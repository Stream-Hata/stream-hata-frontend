# Plan — Nameless StreamHata

Единый план по основному приложению, админке и инфраструктуре. Старые разделы слиты в этот документ.

## Продукт

Платформа для одного стримера: Twitch-авторизация, игры, рулетка/колесо, баллы, музыка, виджеты, оверлеи. Desktop — Tauri, облачный API — Go + PostgreSQL.

## Текущая архитектура

- Backend: `<backend-host>`, systemd `nsh-backend`, без локальной БД; данные читает/пишет только с `<db-host>`.
- PostgreSQL 18: `<db-host>`, приватный WireGuard (внутренняя сеть), `sslmode=require`, ufw: 22/80/443/51820, 5432 только на wg0.
- Основной фронт: `https://streamhata.rdpctd.dev` (HTTP/2, Let's Encrypt).
- Админка: `https://streamhata-admin.rdpctd.dev` — **отдельный Angular-проект `admin/`**, свой nginx/static, прокси `/rgg-sync/` и `/twitch/`.
- Безопасность: fail2ban (sshd/nginx), rate limit API, security headers.
- RAM: backend ~320 МБ (без каталога в памяти); каталог и кеш — в PostgreSQL.
