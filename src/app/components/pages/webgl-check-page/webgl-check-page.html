Проверка WebGL2

Эта страница проверяет, умеет ли ваш OBS Browser Source рисовать WebGL2. Откройте её внутри OBS, а не в обычном браузере.

Что делать по шагам

  1. В OBS добавьте источник Browser (Browser Source).
  2. В поле URL вставьте ссылку этой страницы: {{ location }}.
  3. Ширина/высота — например 1280×720, галочка «Обновить при появлении» — включена.
  4. Нажмите OK и посмотрите на статус выше. Если «WebGL2 работает» — всё готово.
  5. Если «WebGL2 недоступен»: включите аппаратное ускорение в OBS и в browser source, обновите OBS/плагин, перезапустите OBS.
  6. После проверки замените URL на ссылку нужного виджета из раздела «Виджеты».
