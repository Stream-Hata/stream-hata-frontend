## [1.0.0-alpha.1] - 2026-11-03

### Alpha
- Первый alpha-релиз 1.0: мессенджер, OBS-редактор, мониторинг, алерты, обновления и мультиаккаунт.
- Реакции, пересылка, поиск, редактирование, блокировка и удаление диалогов.
- Поиск стримеров вне контактов и переход в Twitch-чат.
- Read receipts и тихие часы уведомлений.
- Стабильное контекстное меню и авторастущее поле ввода.

### Известные ограничения
- Групповые чаты, голосовые и вложения ещё не готовы.
- Нет полной локализации, мобильного клиента и Plugin SDK.
- Сигналы отношений из Twitch ограничены сообщениями.
- Stream Health без bitrate/jitter/audio clipping.
- Windows-сборка и SMTP-инциденты требуют отдельной проверки.

## [0.6.0-pre-alpha] - 2026-10-26

### Добавлено

- Пользовательское соглашение перед запуском с отдельным пунктом об ответственности за безопасность ПК и keychain.
- Нативный онбординг-вопрос после соглашения с тремя вариантами и пояснениями.
- Шуточный режим вируса: заголовок окна, предупреждающий баннер и свитч в настройках.
- Steam-аватар в плавающем desktop-блоке рядом с профилем.
- Страница `/terms` и ссылка на соглашение из FAQ.
- Документация: `README.md`, `docs/USER_GUIDE.md`, README desktop-клиента.
- Windows CI для сборки MSI/NSIS и updater-артефактов.
- TTS-озвучка русских донатов через Google TTS с кэшированием.

### Изменено

- Акцентный цвет теперь применяется по всему интерфейсу, включая secondary-кнопки, тени, рамки и градиенты.
- Secondary-кнопки получили отдельный outline-стиль.
- Для тёмных акцентных цветов автоматически выбирается белый текст и контрастная тень.
- Тема переключается через `tuiTheme` на `tui-root`; системная тема следует `prefers-color-scheme`.
- Плотность интерфейса меняет spacing-переменные.
- Настройки внешнего вида сохраняются локально и отправляются на сервер.
- Баннер обновления больше не возвращается после перезагрузки.
- i18n для блока «Внешний вид» и страницы игр.

### Исправлено

- Свитч шапки сайдбара работает в обе стороны.
- Кнопка сворачивания находится внутри шапки сайдбара.
- Окно онбординга закрывается после «Продолжить».
- Окно changelog открывается только после согласия.
- Уведомление об обновлении не пропадает после нажатия «Обновить».
- TTS больше не падает на русском тексте из-за условий Groq.

## [0.5.5-pre-alpha] - 2026-10-26

### Desktop и Tauri

- Полноценный desktop-клиент: отдельное окно, системный трей, splash-экран и единый инстанс приложения ([08b3d50](https://github.com/p7x-dev/rgg-inventory-2/commit/08b3d50)).
- Закрытие окна сворачивает приложение в трей; повторный запуск разворачивает уже работающий экземпляр.
- Вход через системный браузер с одноразовым кодом; refresh-токен хранится только в OS keychain.
- Нативное окно «Что нового» на GTK (Linux) и TaskDialog (Windows) с кнопками «Посмотреть», «Пропустить» и чекбоксом «Не показывать больше».
- Полный changelog с разделами, ссылками на коммиты и описанием изменений.
- Верхняя шапка desktop-приложения скрыта; поиск и профиль вынесены в анимированный блок справа снизу.
- Локальный виджет «Система»: CPU, GPU, память, swap, сеть, процессы, аптайм и диски.
- OBS-оверлей системных метрик на `127.0.0.1:17890` с настройкой состава и частоты обновления.
- Поддержка GPU: NVML/AMD sysfs на Linux и WMI GPU Engine на Windows.
- Windows-код проверен сборкой под `x86_64-pc-windows-gnu`; TaskDialog и системные метрики компилируются.

### Уведомления

- Системные уведомления desktop-приложения: фолловеры, подписки, подарки, продления, рейды, новые зрители и обновления.
- Учёт фокуса окна и режима «Тихий режим».
- Отдельная страница настроек уведомлений с сохранением на сервере.

### Игры и каталог

- Steam добавлен как источник импорта на странице игр: поиск и добавление по названию.
- Фоновое обогащение теперь проходит по всем играм каталога, включая записи из RGG-списка.
- При открытии детальной страницы игра ставится в очередь на поиск во всех доступных источниках.
- Страница игры автоматически обновляется после фонового обогащения.
- Исправлен поиск игр с нелатинскими названиями: русские, корейские и японские тайтлы больше не теряются при сопоставлении.
- Детальная страница игры открывается без ожидания синхронного обогащения.
- Источники показываются по факту: Steam, RAWG, IGDB, MobyGames и другие, а не только «RGG».
- Добавлен перевод англоязычных описаний на русский с кэшированием.
- Улучшены карточки игр, жанры и русские названия, где источник их отдаёт.

### Виджеты и стрим

- Виджеты: Hotbar, Roulette, Chat Jury, Timer, Alerts, Event List, Audio и System.
- Включение и выключение виджетов, настройка и копирование URL для OBS Browser Source.
- Названия, действия и подписи виджетов переведены через i18n.
- Рулетка ускорена: быстрый старт, основная часть пути за ~65% времени и плавное замедление только у выигрышного лота.
- Улучшена анимация холостого хода рулетки.

### Интерфейс и i18n

- Русский и английский языки интерфейса, переключение без перезагрузки.
- Переведены навигация, настройки, уведомления, системный виджет, страница игр и виджеты.
- Добавлены ключи для импорта, фильтров, статусов и ошибок.
- Улучшена адаптивность sidebar, поиска и плавающего desktop-блока.

### Исправления

- Клики по переключателям Taiga в Tauri WebView.
- Зависания и лишние перезагрузки при открытии игр.
- Открытие внешних ссылок в системном браузере вместо WebView.
- Фильтрация ботов в чате, зрителях и баллах.
- Ограничения API и повторные запросы при обогащении каталога.
- Отображение источников и описаний у игр из RGG-списка.

### Инфраструктура

- Go-бэкенд с PostgreSQL, OpenBao и systemd-запуском без plaintext-секретов.
- Tauri updater и подписанные обновления.
- Кэш обогащения и повторные попытки для всех игр.
- Локальный HTTP-сервер метрик и OBS-оверлея.

### Известные ограничения

- Steam bulk-import по библиотеке пока не реализован — доступен импорт по названию.
- Не все ретро/японские/корейские игры находятся в RAWG, IGDB или Steam автоматически.
- Windows-установщик ещё не опубликован.
- Часть внешних описаний может оставаться на английском, если переводчик недоступен.
