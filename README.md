# Nameless StreamHata

[English version](README.en.md)

**Nameless StreamHata** — открытая панель управления Twitch-стримом и набор OBS-виджетов. Она объединяет каталог игр, рулетку, баллы, чат-жюри, модерацию, донаты, музыку, уведомления и desktop-клиент в одном рабочем месте стримера.

Текущая версия: **0.6.0-pre-alpha**.

## Для кого

- для Twitch-стримеров, которым нужна одна панель вместо десятка вкладок;
- для небольших каналов и community-проектов;
- для тех, кто хочет управлять OBS-оверлеями без ручной верстки;
- для разработчиков, которые хотят расширять открытый проект.

## Что умеет

### Панель стримера

- Дашборд с состоянием канала, эфира и последними событиями.
- События: фолловеры, подписки, подарки, рейды, донаты и награды.
- Уведомления и настройки системных уведомлений в desktop-клиенте.

### Игры и каталог

- Каталог игр с поиском, фильтрами, платформами, тирами и эмуляторами.
- Импорт из RAWG, IGDB и Steam.
- Карточка игры с обложкой, описанием, жанрами, источниками и ссылками.
- Фоновое обогащение данных из внешних сервисов.
- Steam-аватар и профиль в desktop-клиенте.

### Стрим и сообщество

- Рулетка и колесо с настройкой пула и анимации.
- Хотбар платформ, таймеры и алерты.
- Баллы, награды, опросы и чат-команды.
- Чат-жюри: голосование зрителей и AI-вердикт.
- Модерация: фильтры, правила и действия против спама.

### Донаты, музыка и озвучка

- Донаты через DonationAlerts и другие провайдеры.
- Донат-карточка, таблица, цель и звук.
- TTS-озвучка донатов: Groq для английского, Google TTS для русского с кэшем.
- Музыка: очередь треков и текущий трек.

### OBS-виджеты

- Hotbar, Roulette, Chat Jury, Timer, Alerts, Event List, Audio и System.
- Включение/выключение, настройка и копирование URL для Browser Source.
- Локальный виджет «Система»: CPU, GPU, память, сеть, процессы, аптайм и диски.
- OBS-оверлей системных метрик на `http://127.0.0.1:17890/`.

### Desktop-клиент

- Tauri 2: отдельное окно, трей, splash и единый инстанс.
- Вход через системный браузер, токен в OS keychain.
- Нативные диалоги соглашения и changelog.
- Системные уведомления и автообновления.
- Плавающий блок поиска и профиля справа снизу.
- Windows/Linux сборка.

## Как это работает

```text
Twitch / Steam / RAWG / IGDB
             │
             ▼
      Go backend (API, OAuth, EventSub, IRC)
             │  PostgreSQL + OpenBao
             ▼
   Angular panel  ──────────────►  OBS Browser Source
             │                         (виджеты)
             ▼
      Tauri desktop
   (Rust: окно, трей, keychain,
    уведомления, метрики)
```

- **Frontend** на Angular + Taiga UI отвечает за панель и публичные страницы.
- **Backend** на Go принимает события Twitch, хранит состояние, отдаёт API и генерирует оверлеи.
- **OBS** открывает URL виджета как Browser Source; панель управляет его настройками.
- **Desktop** на Tauri загружает ту же панель, но добавляет нативные функции через Rust-команды.
- **Секреты** хранятся в OpenBao и системном keychain, а не в репозитории.

## Быстрый старт

### Frontend

```bash
pnpm install
pnpm start
```

Откройте `http://localhost:4200/`.

### Сборка

```bash
pnpm build
```

Результат: `dist/nameless-streamhata/browser`.

### Desktop

```bash
git clone https://github.com/Stream-Hata/streamhata-desktop.git
cd streamhata-desktop
cargo build --release
```

Нужны Rust и системный WebView: WebKitGTK на Linux, WebView2 на Windows.

### Backend

Backend собирается отдельно из `nameless-streamhata-backend` и требует PostgreSQL и OpenBao. Параметры подключения задаются переменными окружения; секреты не коммитятся.
