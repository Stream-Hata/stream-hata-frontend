# Nameless StreamHata

[English version](README.en.md)

**Nameless StreamHata** — открытая панель управления Twitch-стримом, набор OBS-виджетов и desktop-клиент. Проект объединяет каталог игр, рулетку, баллы, чат-жюри, модерацию, донаты, музыку, уведомления и локальные метрики в одном рабочем месте стримера.

Текущая версия: **0.6.23-pre-alpha**. Проект находится в активной разработке.

## Что это

StreamHata — это не просто страница со статистикой. Это рабочая панель, которая:

- принимает события Twitch через backend;
- хранит настройки канала, игры, баллы, донаты и виджеты;
- отдаёт OBS-оверлеи как обычные Browser Source;
- управляет OBS через WebSocket;
- работает как desktop-приложение на Tauri с доступом к системе.

Панель не заменяет OBS. OBS отвечает за сцены, звук и запись; StreamHata управляет данными, оверлеями и автоматизацией.

## Для кого

- Twitch-стримеры, которым нужна одна панель вместо десятка вкладок;
- небольшие каналы и community-проекты;
- ведущие ивентов, турниров и розыгрышей;
- разработчики, которые хотят расширять открытый проект.

## Возможности

### Панель стримера

- Дашборд: состояние канала, эфира, события и быстрые действия.
- Лента событий: фолловеры, подписки, подарки, рейды, донаты, награды.
- Уведомления и настройка их типов.
- Профиль, роли, Steam-библиотека и достижения.

### Игры и каталог

- Каталог игр с поиском, фильтрами, платформами, тирами и эмуляторами.
- Импорт из RAWG, IGDB и Steam.
- Обогащение карточек из внешних источников.
- Steam-аватар и данные профиля в desktop.
- Публичные страницы игр, заявок и событий.

### Стрим и OBS

- Подключение OBS WebSocket.
- Сцены, источники звука, mute/unmute.
- Старт/стоп стрима и записи, сохранение replay-буфера.
- Информация канала, название стрима и игра.
- Таймер, алерты и события.

### Сообщество

- Чат-жюри: голосование зрителей и AI-вердикт.
- Команды голосов настраиваются: по умолчанию `!yea` и `!nei`, также работают сообщения и emote `yea`/`nei`.
- Баллы, награды, опросы, предсказания и чат-команды.
- Модерация: фильтры, правила и AI-проверка.
- Рейды, достижения и watch streak.

### Донаты, музыка и TTS

- Донаты через DonationAlerts и другие провайдеры.
- Донат-карточка, таблица, цель и звук.
- TTS-озвучка донатов: Groq для английского, Google TTS для русского с кэшированием.
- Музыка: очередь, текущий трек и управление воспроизведением.

### Виджеты и оверлеи

- Hotbar, Roulette, Chat Jury, Timer, Alerts, Event List, Audio, System.
- Включение/выключение, настройка и копирование URL для OBS.
- Локальный виджет «Система»: CPU, GPU, память, сеть, процессы, диски.
- OBS-оверлей метрик: `http://127.0.0.1:17890/`.

### Desktop-клиент

- Tauri 2 + Rust.
- Трей, splash, единый инстанс и закрытие в трей.
- Вход через системный браузер, токен в OS keychain.
- Нативные диалоги соглашения и changelog.
- Системные уведомления и OTA-обновления.
- Проверка обновлений в фоне и вручную, прогресс скачивания и установки.
- Плавающий блок поиска и профиля.
- Кот-напоминание после простоя без стрима: анимированный SVG, озвучка, три стадии, иконка в трее.

## Как это работает

```text
Twitch / Steam / RAWG / IGDB / OBS
                  │
                  ▼
        Go backend (API, OAuth, EventSub, IRC)
                  │  PostgreSQL + OpenBao
                  ▼
     Angular panel ───────────────► OBS Browser Source
                  │                     (виджеты)
                  ▼
          Tauri desktop
   (Rust: окно, трей, keychain,
    уведомления, метрики, OTA)
```

- **Frontend** — Angular 22 и Taiga UI 5.
- **Backend** — Go: Twitch OAuth, EventSub/IRC, каталог, баллы, донаты, музыка, виджеты.
- **PostgreSQL** — данные и настройки.
- **OpenBao** — серверные секреты.
- **OBS** — открывает URL виджета как Browser Source.
- **Tauri** — desktop-оболочка, системные команды и обновления.

## Быстрый старт

### Требования

- Node.js 20+;
- pnpm 11+;
- для desktop: Rust и системный WebView;
- для backend: Go, PostgreSQL, OpenBao.

### Frontend

```bash
pnpm install
pnpm start
```

Откройте `http://localhost:4200/`.

### Сборка

```bash
pnpm build
```

Результат: `dist/nameless-streamhata/browser`.

### Desktop

```bash
git clone https://github.com/Stream-Hata/streamhata-desktop.git
cd streamhata-desktop
cargo build --release
```

Linux: WebKitGTK 4.1. Windows: WebView2 и MSVC.

### Backend

```bash
git clone https://github.com/Stream-Hata/nameless-streamhata-backend.git
cd nameless-streamhata-backend
go build ./...
```

Параметры БД и OpenBao задаются через окружение; секреты не коммитятся.

## Desktop и OTA

Desktop-клиент собирается из отдельного репозитория. OTA использует:

- GitHub Releases;
- `latest.json` в релизе;
- minisign-подпись артефактов;
- fallback на `https://streamhata.rdpctd.dev/desktop/latest.json`.

Проверка обновлений идёт при старте и раз в 30 минут. Уведомление появляется только если артефакт реально доступен. Установка требует подтверждения, показывает шаги и прогресс, затем приложение перезапускается.

## Безопасность

- Пароль Twitch вводится только на сайте Twitch.
- Desktop-токен хранится в системном keychain.
- Серверные секреты — в OpenBao.
- Не публикуйте webhook URL, токены ботов и OAuth-секреты.
- Проверяйте источники игр и ROM; часть материалов может нарушать законодательство.
- При подозрении на кражу токена отзовите сессии Twitch и смените пароли.
